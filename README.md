Сборник лабораторных работ (Python): очистка данных, визуализация, классификация, CNN, кластеризация текстов.





## Структура


- `lab1_cv_shapes/` — генерация фигур и детекция контуров (OpenCV/Matplotlib)


- `lab2_bank_churn_cleaning/` — препроцессинг churn-датасета + кросс-таблицы


- `lab3_loan_approval_models/` — пайплайны (OneHot/Scale) + LR/NB/RF + GridSearch


- `lab4_sneakers_cnn/` — бинарная классификация Nike/Adidas на Keras


- `lab5_text_clustering_wiki/` — TF‑IDF + KMeans/HC/DBSCAN, t‑SNE





Все наборы данных — внешние/пользовательские; в репозитории только код и инструкции.
